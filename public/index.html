    Comment ça marche ? +

    Chaque personne offre un cadeau à un participant différent d’elle-même et reçoit un cadeau. Si le bonus est activé, une personne tirée au sort offre un deuxième cadeau à un destinataire différent de son premier.

    L’organisateur lance le tirage via GitHub Actions. Le résultat est enregistré dans public/data/election.json, puis le site est mis à jour automatiquement.

    Ce dépôt est public : les attributions sont consultables dans le fichier JSON. Le récapitulatif du tirage est affiché à tous sur cette page.
