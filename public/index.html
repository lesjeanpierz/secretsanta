    Comment ça marche ? +

    Dans l’ordre de la liste, chaque participant offre un cadeau à une personne tirée au sort parmi celles qui n’ont pas encore été choisies, en s’excluant lui-même. Si la liste est impaire, le dernier participant choisit parmi tous les autres, même ceux déjà sélectionnés : il peut ainsi attribuer un deuxième cadeau à un destinataire. Le dernier participant peut lui-même avoir été choisi auparavant. Personne ne s’offre de cadeau à soi-même.

    L’organisateur lance le tirage via GitHub Actions. Le résultat est enregistré dans public/data/election.json, puis le site est mis à jour automatiquement.

    Ce dépôt est public : les attributions sont consultables dans le fichier JSON. Le récapitulatif du tirage est affiché à tous sur cette page.
